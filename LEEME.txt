MEJORA +49 — Corrección: opciones de Ajustes Generales que "no se guardaban" (v1.48.0)

CAUSA RAÍZ ENCONTRADA (confirmada con prueba directa en base de datos):
La política de seguridad (RLS) de app_settings exigía una sesión de Supabase
Auth REAL activa (auth.role()='authenticated') para poder guardar cambios.
Si esa sesión no estaba activa en el momento exacto de guardar — por ejemplo,
si expiró silenciosamente, o si el superadministrador nunca completó el paso
de "Acceso administrador" con su contraseña de Supabase antes de tocar
Ajustes Generales — el guardado se bloqueaba con CERO filas afectadas y
SIN ERROR VISIBLE. La app mostraba "✅ Guardado correctamente" en pantalla,
pero en realidad no se había escrito nada en la base de datos. Por eso, al
volver a entrar, las opciones aparecían como si nunca se hubieran configurado.

Se reprodujo el bug exacto en base de datos (UPDATE directo sin sesión Auth
→ 0 filas, sin error) y se confirmó la corrección (mismo escenario, ahora vía
RPC → guarda correctamente, o avisa con un error claro si el usuario no es
superadministrador).

CORRECCIÓN APLICADA:
Todos los guardados de Ajustes Generales ahora usan funciones del servidor
(RPC) que validan directamente contra la tabla de superadministradores, sin
depender de esa sesión Auth frágil:
- Empresa contratante (nombre + NIT)
- Correo de pedidos
- Límites del sistema (PDV, vendedores, distribuidores, niveles)
- Tema visual (Claro/Oscuro/Pastel)
- Logo de la empresa (subir/quitar)
- Switch de conexión vía link (precios/stock)
- Switch del Motor de Aprobación de Pedidos + tarifa de IVA
- Selector Manual/Vía link (precios y stock)

Este es el MISMO patrón de seguridad (RLS cerrado, acceso solo vía funciones
SECURITY DEFINER) que ya usa el proyecto hermano RADAR-INDUSTRIAL desde el
18 de agosto — se aplicó a propósito de forma consistente pensando en la
futura fusión de ambas apps: cuando se unifiquen, el patrón de guardado de
configuración ya coincide entre las dos.

PENDIENTE (no reportado por el usuario todavía, detectado en la revisión):
Las etiquetas de "Destacados" (Foco/Best Seller/Ofertas) en el panel
Destacados usan todavía el mismo patrón antiguo (UPDATE directo). Se dejó
pendiente de una próxima mejora, ya que el usuario reportó específicamente
Ajustes Generales.
