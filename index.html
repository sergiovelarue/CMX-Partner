Detalle del producto

🔧 Lista de precios 1 — Administración

Visible solo para el administrador autenticado. Esta es la Lista de precios 1 (base): el PVP con IVA de cada producto, la referencia de partida para todos los Niveles de descuento. Los cambios aquí afectan a todos los usuarios de inmediato.

Actualizar un precio individual

Carga masiva de Lista de precios 1 (CSV)

Columnas requeridas: referencia, descripcion, gama, producto, c01. Opcional: activo (si se omite, se asume activo). ⚠️ Los productos que NO estén en el archivo quedarán marcados como inactivos (no se borran).

📎 Información técnica del producto (imagen, plano, manual, video)

Imágenes y PDF se suben directo aquí. Para video, pega el enlace de YouTube/Vimeo (no se sube el archivo).

📦 Disponibilidad MTS / MTO — actualizar una referencia

MTS (Make to Stock): se muestran unidades disponibles y próximas a llegar. MTO (Make to Order): se muestran días de entrega aproximados.

📦 Disponibilidad MTS / MTO — carga masiva (CSV)

Columnas requeridas: referencia, tipo_abastecimiento, unidades_disponibles, unidades_proximas_llegar, fecha_estimada_llegada, dias_entrega_aprox. fecha_estimada_llegada en formato AAAA-MM-DD. Deja vacías las columnas que no apliquen según el tipo.

👥 Usuarios

Visible solo para el administrador autenticado.

👤 Administradores

Solo un administrador ya autenticado puede agregar o quitar a otro. El correo se agrega aquí; la contraseña se crea aparte en Supabase (Authentication → Users) con ese mismo correo.

🏢 Propietario de Distribuidor

Se crea junto al distribuidor (sección Distribuidores, abajo). Aquí solo se lista.

🏬 Administrador PDV

Se auto-registra con correo + código de distribuidor. Aparece aquí al registrarse.

🧾 Dependiente PDV

Se auto-registra con correo + código de distribuidor. Aparece aquí al registrarse.

🧑‍💼 Vendedores de distribuidor

Vendedor que se registró con el código de un distribuidor real (no de la empresa contratante). Aparece aquí al registrarse.

🏬 Distribuidores

Nace en Nivel 1; reasigna el nivel en la tabla. Código no obvio: habilita también el registro de Admin PDV y Dependientes.

Con correo: crea también al Propietario. Ingresa con ese correo + el código de distribuidor, igual que Admin PDV.

🧑‍💼 Vendedores

Vendedores de planta, no asociados a un distribuidor. Ingresan con correo + teléfono + este código.

Si cambias el código, los vendedores de la empresa deberán volver a ingresar como la primera vez.
